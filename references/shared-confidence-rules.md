# 法条引用置信度标注与交付分项置信度规范

> 公共复用模块，被模块A/B/C/D及所有模板引用（1.1.0 新增）。
> 触发时机：任何回复/文书中**引用法条**时、模块B/C 交付**文书/报告**末尾、模块A/D 交付**咨询/材料**末尾。
> 核心原则：**来源透明，未标注视为未核验；宁可降档，不可冒充。**

## 1. 法条引用四档置信度标注

每条法条引用必须落在以下四档之一，并在引用处**行内标注档位符号**。未标注档位 = 自动视为「未核验·模型生成」。

| 档位 | 名称 | 判定标准 | 行内标注 | 复核指引 |
|:---|:---|:---|:---|:---|
| 🟢 1档 | **已核验·flk API** | 经 `scripts/flk_npc_client.py` 实时调用 flk.npc.gov.cn API，返回条文号与原文一致 | `[已核验·flk API]` | 无需复核；仍提示"以官方最新文本为准" |
| 🟢 2档 | **已核验·单源** | 来自单一权威源（官方网站页面、官方发布的单行本/公报、中国裁判文书网原文），非 API 但可给出可查证来源 | `[已核验·单源]` | 保留来源链接/出处供用户自查 |
| 🟡 3档 | **已引·离线库** | 来自 AI 训练知识库或技能包内置模板/速查表（如 case-*.md、shared-limitation-periods.md 的既有条文），未实时核验 | `[已引·离线库]` | 建议用户访问 flk.npc.gov.cn 人工复核条文号与时效性 |
| 🔴 4档 | **未核验·模型生成** | 无任何来源支撑、由模型自行生成或凭记忆补全的条文表述 | `[未核验·模型生成]` | 🔴 强制附复核提示："本条未经权威源核验，请务必核对官方原文后使用，必要时删除该引用" |

**引用格式统一示例：**
- 🟢 `[已核验·flk API]`《中华人民共和国民法典》"第577条 当事人一方不履行合同义务或者履行合同义务不符合约定的，应当承担继续履行、采取补救措施或者赔偿损失等违约责任。"
- 🟡 `[已引·离线库]`《中华人民共和国劳动争议调解仲裁法》"第27条 ……"
- 🔴 `[未核验·模型生成]`（仅在 API 与知识库均无来源、且必须给方向性提示时使用；优先改为"据相关法律规定"，不得编造精确条文号）

**与既有双通道标记的关系：**
`shared-statute-engine.md` 的 `[数据来源：flk.npc.gov.cn]` 即 🟢1档；`[数据来源：AI知识库]` 默认落 🟡3档，如模型对条文内容无把握则落 🔴4档。引用时可两标记并存，但**必须能映射到四档之一**。

## 2. 法条基线日期与超期自动降档

### 2.1 基线日期声明

- 本技能包内置模板、速查表、case-*.md 中的既有条文引用，统一以**最近一次官方核验日期**为 `法条基线日期`（law_baseline_date），并在引用该批条文时声明。
- 交付物涉及模板/内置条文时，在交付末尾注明：`法条基线日期：YYYY-MM-DD`。
- 通过 flk API 实时核验的引用，基线 = 本次调用日期，随回复即时更新。

### 2.2 超期自动降档

| 情形 | 处理 |
|:---|:---|
| 距基线日期 ≤180 天 | 维持原档位（如内置条文按 🟡3档提示复核） |
| 距基线日期 >180 天，且未重新实时核验 | **自动降档一级**：原 🟢2档 → 🟡3档；原 🟢1档若引用自模板旧文 → 按 🟡3档并标注"该条超180天未实时核验"；任何档位超期均不得标为 🟢1档 |
| 已废止/新修订（如新旧法交替） | 立即降档至 🔴4档并删除或替换为现行条文，不得以旧条文号照抄（警示：法律修订后条文号与内容可能整体漂移，勿凭"号不变"假设） |

- 判定动作：引用模板/速查表条文前，先看其是否有基线日期声明；无声明的一律按"超期未核验"处理为 🟡3档以下。
- 模块A A8 维度一"法条可溯源校验"应增加一条：`引用是否满足四档标注 + 是否超180天未核验？不通过动作：补档或降档。`

## 3. 交付末尾分项置信度标注（法条/事实/金额/程序 四维）

**模块A/B/C/D 每次最终交付（咨询意见、起诉状草稿、法条分析、刑事材料）末尾**，除免责声明外，追加分项置信度标注，四维独立给档：

| 维度 | 含义 | 档位 | 说明 |
|:---|:---|:---|:---|
| 法条 | 本文引用法条的整体核验水平 | 🟢已核验 / 🟡离线待复核 / 🔴未核验 | 按第1节四档汇总 |
| 事实 | 关键时间、主体、事件是否来自用户确认 | 🟢用户确认 / 🟡部分待补 / 🔴含假设 | 用户口述未回核的内容不视为已确认 |
| 金额 | 本金/利息/赔偿计算基数与公式是否可复核 | 🟢有计算式且基数已确认 / 🟡基数待确认 / 🔴纯估算 | 见 shared-delivery-rules.md 要素确认闸门 |
| 程序 | 管辖、时效、前置程序等程序判断依据是否核验 | 🟢已核验 / 🟡需律师复核 / 🔴不确定 | 模块B交付前按 module-b 程序法五查执行 |

**标注模板：**

```
【分项置信度】
法条：🟢 已核验（flk API 实时核验）/ 🟡 / 🔴
事实：🟢 用户已确认 / 🟡 部分待补 / 🔴 含假设
金额：🟢 基数已确认+有计算式 / 🟡 基数待确认 / 🔴 纯估算
程序：🟢 已核验 / 🟡 需律师复核 / 🔴 不确定

⚠️ 整体定级：任一维度为 🔴 或 事实/金额为 🟡 时，本交付**不得标注"可直接使用"**，
统一改为："草稿级：请核对【待补】项并由执业律师审核后再使用/提交"。
```

**整体可用性判定规则（硬性）：**
1. 法条 / 事实 / 金额 / 程序 四维**任一维为 🔴（未核验）** → 整体不得标"可直接使用"。
2. 文书（起诉状、控告材料等）涉及**事实 🟡 或 金额 🟡** → 整体标注"草稿级"，并逐项列出【待补】。
3. 仅纯咨询类答复可适度放宽（🟡 即可交付），但法条维 🔴 时必须先删改或降级为"据相关法律规定"。
